01 / THE PROCESS

One fixed order.
Room for doubt.

The intended behavior is to make uncertainty visible and route unclear cases to a person. The system still needs human oversight.

  1. 01 →

    Read PDF

    Start with the supplier’s quotation text.

  2. 02 →

    Extract facts

    Record the values and their source evidence.

  3. 03 →

    Check

    Compare with the purchase request and company rules.

  4. 04 →

    Decide

    Approve, reject, or flag uncertainty.

  5. 05

    Report / ask

    Show why. Ask a person when the answer needs review.

02 / THE EXPERIMENTS

Better questions.
Different answers.

Each version tested a different idea. Every metric below covers the same ten development PDFs, with the policy caveat on the final approach.

APPROACH01

Do we even need AI?

Plain rules

Read and check the quotation using Python rules. No AI.

Plain code recovered 267 of 270 facts. Strong extraction did not resolve every wording difference: only 6 verdicts matched.

Where does AI help?

First AI attempt

Ask a model to understand and report the document.

APPROACH03

Can it be dependable?

Strict contract

Give the AI and code a tighter output contract.

The model stayed the same; the contract changed. Verdict matches rose to 7 and fact recovery to 262. Some ambiguous and missing clauses remained unresolved.

APPROACH04

Can it judge safely?

Reader + judge

One agent records facts and doubts. A second applies the rules.

The judge reads the full document and explains each rule. It matched 9 verdicts, including a policy change after reviewing packs 06 and 08. It took longer and still missed pack 01.

02 / COMPARISON

The policy changed

The 9/10 includes a decision made after viewing packs 06 and 08: read the rules literally. Approaches 1–3 did not get it. 9 versus 7 is not like for like.

03 / EVALUATION

Single runs, limited audit

Model output can vary. An AI assistant audited fact labels; independent humans did not.

04 / SAFETY

No approval code guard

Approach 4 relies on its judge, fail-closed handling and a prompt-injection rule. Injection testing covered only two packs and one model.

05 / PRIVACY

Hosted means third-party

Hosted models send document text to a third party. All samples shown here are fictional.
