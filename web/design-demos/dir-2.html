01 / THE WORKFLOW

A fixed path through the uncertainty.

The same order every time. Evidence first, rules next. Unresolved cases are intended to go to a person.

01 →

Read the PDF

Start with the supplier’s actual words.

02 →

Extract facts

Capture values, quotes and uncertainty.

03 →

Check the rules

Compare with the request and policy.

04 →

Make a decision

Approve, reject, or request review.

05 ↗

Report the evidence

Show why. Let a person resolve doubt.

This is the intended review behavior. Model judgments can still be wrong; the limits are part of the result.

02 / FOUR APPROACHES

Better questions. More useful answers.

We started with plain code, then tested where AI helped—and where the hand-off broke.

Plain rules

Do we even need AI?

Plain Python rules, without a model. The baseline reads 267 of 270 facts correctly.

Strict contract

    05 / HONEST LIMITS

    What these results
    can’t tell us.

    A useful demonstration should show its boundaries as clearly as its best result.

    Revisit the evidence ↑
    01

    Development scores, not unseen accuracy

    All ten PDFs were visible while building. These scores are not a test on unseen documents.

    02

    The policy changed before the final approach

    9 of 10 includes a decision made after looking at packs 06 and 08: read the rules literally. Approaches 1–3 did not get this change. 9 versus 7 is not like for like.

    03

    Single runs, without independent human auditing

    Model output can vary. Fact labels were audited by an AI assistant, not by independent humans.

    04

    No code guard on approach 4’s approvals

    Safety rests on the judge model, fail-closed handling and a prompt-injection rule. Injection testing covered only two packs and one model.

    05

    Hosted models receive document text

    The text is sent to a third party when hosted models run. These sample documents are fictional.

    06

    Fully local inference was too slow

    The reported local experiment on a 12 GB GPU exceeded ten minutes per call. This is separate from the five-PDF rerun.
